# Zhibin Tan's Personal Homepage

Personal academic website for **Zhibin Tan (谭志斌)**, Assistant Professor at the School of Digital Economics, Shanghai University of Finance and Economics.

## Site design

- English is the default language.
- A prominent language switch in the top-right corner toggles between **中文** and **English**.
- Responsive single-page academic layout for desktop, tablet, and mobile.
- Sections: About, Research, Publications & Working Papers, Honors & Grants, Teaching, Academic Service, and Contact.

## Main files

- `index.html` — page content and bilingual text
- `styles.css` — responsive visual design
- `script.js` — language switching and preference persistence
- `.nojekyll` — serves the site as a plain static website on GitHub Pages

## Source material

The content was consolidated from:
1. Shanghai University of Finance and Economics faculty profile
2. Zhibin Tan's previous Weebly homepage
3. Updated academic CV dated May 23, 2026

Where older information differed, the latest CV and current SUFE faculty page were treated as the primary sources.
